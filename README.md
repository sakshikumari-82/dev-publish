# Dev Publish

A developer-first blogging and publishing platform built for engineers to share technical knowledge, discover useful content, and build a developer community.

## Live Demo

https://developer-publishing-platform--sakshistore.replit.app/

## Project Overview

Dev Publish is a full-stack developer publishing platform inspired by modern developer blogging communities.

The platform supports user authentication, article publishing, drafts, categories, tags, search, likes, comments, bookmarks, follows, notifications, author profiles, moderation, and monetization foundations.

## Key Features

- User Signup and Login
- Secure Authentication
- Author Profiles
- Create, Edit and Delete Posts
- Draft and Published Posts
- Markdown Content
- Categories and Tags
- Article Search
- Likes
- Comments and Replies
- Bookmarks
- Follow System
- Notifications
- Author Workspace
- Moderation and Reports
- Monetization and Advertising Foundations

## Technology Stack

### Frontend
- React
- TypeScript
- React Router
- React Query
- CSS

### Backend
- Node.js
- Express.js
- REST APIs
- Zod Validation
- JWT Authentication

### Database
- PostgreSQL
- Drizzle ORM

## Project Architecture

- `artifacts/dev-publish` — Frontend application
- `artifacts/api-server` — Express backend/API
- `lib/api-spec` — API specification
- `lib/api-client-react` — API client
- `lib/api-zod` — Validation and types
- `lib/db` — Database schema and connection

## Security

The application uses secure password hashing, JWT-based authentication, PostgreSQL-backed sessions, protected routes, role-based authorization, and request validation.

## Monetization Foundation

The project includes a provider-neutral foundation for future legitimate monetization such as advertising, sponsored placements, creator plans, subscriptions, transactions, earnings and payouts.

No fake traffic, clicks, or revenue generation is used.
